Editorial Handbook

Making a Class

A class is a numbered, titled, ordered playlist that teaches one change a listener can hear. This is how one gets made, from the lineage question to the published list.

Lineage and Numbering

Use the Atlas for direct parent and child connections. Course numbers follow the primary musical lineage. Where influences are shared, describe them without inventing a single parent.

The number is a shelf address, not a claim that every genre has one clean parent: the first digit is the broad historical neighborhood, the second the major traditions side by side, and each decimal a branch (42 ROCK → 42.07 PUNK → 42.07.2 POST-PUNK). Keep the first two levels as written and drop leading zeroes from deeper levels. Put one space between the number and the genre title, then a middle dot before the subtitle. Numbers are never printed on covers.

How Playlists Are Discussed, Built, and Decided

  1. Agree on what the class should teach. Start with a question the listener can answer by ear. State the expected discovery, what makes it surprising, and which musical change the recordings need to demonstrate. Use the Atlas to check lineage and scope before settling the title and number.
  2. Research more recordings than the class will use. Look for roots, defining recordings and later changes that carry the argument forward. Verify original release dates, artist and recording credits, and the role of scenes or production techniques where it matters. Catalog availability can limit the selection. Search across artists, labels, scenes and eras before settling for fewer examples.
  3. Make candidates compete for a place. Ask what each track teaches, why this artist belongs, and whether another recording makes the same point more clearly. Repeat an artist or release only when the tracks show distinct developments, techniques or contrasts. End the selection when the argument is complete or the verified, relevant recordings run out. There is no track quota.
  4. Sequence the class and listen through. Use chronology as the spine. Let the roots establish a sound before later tracks transform it. Check transitions, pacing and repetition. Choose an ending that brings the lesson into focus, and include recent music when it develops the story.
  5. Bring a complete proposal to the discussion. Give the numbered title, public description and ordered track list as three separately copyable parts. Format the list as Artist - Song, one per line. Keep research and the reasons for close choices in the teaching notes so the discussion can focus on the decisions that matter.
  6. Reopen decisions when challenged. If a track, order, title, premise, lineage or historical claim is questioned, listen again and check the evidence against the original listening question. Compare alternatives, decide what to keep or change, and explain the reason. When a change affects other tracks or the ending, check the whole sequence again.

Sample Class Prompt

Copy this example and swap in the style or Atlas node you want to teach.

Build a School of Listening class for Country Rock.

Listening question: What changes when a rock band makes pedal steel and close country harmonies part of its groove?

Use the Music Atlas to verify the direct connections and course number. Research the original recording dates and credits, then choose tracks that let listeners hear the roots, the defining sound and later developments. Compare candidates before deciding. Repeat an artist only when each track makes a distinct point. There is no track quota.

Sequence the class around chronology, with an ear for pacing, transitions and a closing track that brings the lesson into focus. Check the exact recordings in Apple Music before finalizing the list.

Return three separately copyable parts:
1. The numbered class title with a listening-focused subtitle.
2. A one-line public description of up to 300 characters. Start with the active period, describe what to listen for, and use FROM: and LED TO: for up to three direct connections each. Omit LED TO: if the Atlas lists no direct descendants.
3. The ordered playlist, one Artist - Song per line.

Prepare the proposal for discussion.

Descriptions

Keep the public description to one line and 300 characters. Start with the active period, then describe what the music sounds like. Use FROM: and LED TO: for up to three direct connections each; omit the latter when the map gives no direct descendants. Keep extended teaching notes separately.

Publish and Verify

  1. Check titles, credits, exact versions and order in Apple Music first. Prefer the original recording on its original release where available. A remaster or archival issue can carry the same original recording.
  2. Publish the Apple Music list, then copy it to Spotify via Soundiiz. Verify the destination counts, order, versions and public links.
  3. For corrections, verify additions before removing the old playlist entries. Keep the existing playlist identity and document any service differences.
  4. Update the curriculum workbook, then save a text and JSON app manifest with the node ID, title, links, description, art availability, artist credits and ordered tracks for each service.
